# 🚀 나만의 포켓몬 도감 만들기 코딩 마스터 가이드!

안녕! 꼬마 연구원 친구들! 오늘은 파이썬(Python)이라는 마법 주문을 배워서 **나만의 진짜 포켓몬 도감**을 만들어 볼 거예요. 총 7개의 단계를 거치면서 컴퓨터가 어떻게 일하는지 핵심 개념들을 쉽고 재미있게 배워볼 거예요. 준비됐나요? 출발~!

## 🌟 특별 부록: 도대체 API와 JSON이 뭘까요?

본격적으로 코딩을 시작하기 전에, 우리가 1단계에서 만날 두 가지 엄청난 마법 도구, **API**와 **JSON**에 대해 먼저 알아볼게요. 이름은 어렵지만 사실 아주 쉽고 재미있는 친구들이랍니다!

### 1. API (에이-피-아이) : 식당의 친절한 점원 삼촌! 👨‍🍳
여러분이 햄버거 가게에 갔다고 상상해 보세요. 주방(인터넷 서버)에는 맛있는 햄버거(포켓몬 정보)가 아주 많아요. 하지만 여러분이 직접 주방에 들어가서 햄버거를 가져올 수는 없죠? 

이때 필요한 사람이 바로 **점원 삼촌(API)**이에요!
1. 여러분(파이썬)이 점원 삼촌에게 "피카츄 세트 하나 주세요!"라고 **주문(요청, Request)**을 해요.
2. 점원 삼촌(API)은 주방으로 가서 피카츄 세트를 찾아요.
3. 그리고 여러분의 테이블로 피카츄 세트를 **가져다준답니다(응답, Response)**.

즉, **API는 내 컴퓨터가 다른 인터넷 컴퓨터에게 "이 정보 좀 찾아다 줘!"라고 부탁할 수 있게 해주는 연결 통로**예요. 우리는 'PokeAPI'라는 전 세계에서 가장 큰 포켓몬 식당(서버)의 점원 삼촌에게 정보를 부탁할 거랍니다!

### 2. JSON (제이-슨) : 이름표가 붙은 마법의 도시락 통! 🍱
점원 삼촌이 피카츄 세트를 가져왔는데, 만약 햄버거, 감자튀김, 콜라가 다 섞여서 오면 어떨까요? 무엇이 키이고 무엇이 몸무게인지 알 수가 없겠죠.

그래서 전 세계의 컴퓨터들은 정보를 주고받을 때 **JSON**이라는 아주 깔끔한 '마법의 도시락 통'을 사용하기로 약속했어요. JSON 도시락 통에는 음식(데이터)마다 **이름표**가 딱딱 붙어 있어요.

```json
{
  "이름": "피카츄",
  "키": 40,
  "몸무게": 6,
  "타입": "전기"
}
```
어때요? 파이썬도 읽기 쉽고, 우리도 읽기 아주 쉽죠? 이렇게 **"이름표" : "진짜 정보"** 짝꿍으로 정보를 예쁘게 정리해서 담아놓은 상자를 바로 **JSON**이라고 불러요!

## 1단계: 인터넷에서 포켓몬 정보 낚아채기! (`step1_api.py`)

우리가 포켓몬의 키와 몸무게를 다 외울 수는 없죠? 그래서 인터넷에 있는 '포켓몬 식당(API)'에 주문을 해볼 거예요.

### 💡 핵심 개념: Request(요청)와 Header(명찰)
인터넷 식당에 들어갈 때는 예의를 지켜야 해요. 문을 벌컥 열고 "피카츄 줘!" 하면 식당 주인이 놀라서 쫓아낼 수도 있어요. (이걸 에러가 났다고 해요!) 
*   **`Request` (요청)**: 식당에 똑똑 노크하고 정중하게 메뉴를 주문하는 행동이에요.
*   **`Header` (명찰)**: "저는 파이썬을 공부하는 착한 꼬마 연구원이에요!" 하고 보여주는 이름표예요. `User-Agent`라는 명찰을 달아주면 식당 아저씨가 안심하고 문을 열어준답니다.

**코드 설명:**
*   **`urllib.request.Request`**: 인터넷 식당에 전화를 걸어 내 명찰(Header)을 보여주는 파이썬의 스마트폰이에요.
*   **`json.loads`**: 식당에서 배달 온 도시락 통(바이트 덩어리)을 열어서, 파이썬이 읽을 수 있게 예쁘게 상자를 풀어주는 도구랍니다.

## 2단계: 포켓몬 정보 영원히 간직하기 (`step2_csv.py`)

인터넷에서 가져온 포켓몬 정보를 컴퓨터를 끌 때마다 잃어버리면 안 되겠죠? 그래서 엑셀(Excel)처럼 표 모양으로 컴퓨터에 예쁘게 적어둘 거예요.

### 💡 핵심 개념: CSV와 파일 열고/쓰고/닫기
*   **CSV (Comma-Separated Values)**: 이름이 길지만 아주 단순해요! 글씨들을 **쉼표(,)**로 구분해서 적어둔 파일이에요. 예를 들면 `25, 피카츄, 35, 55` 이런 식이죠. 엑셀에서 아주 예쁜 표로 열어볼 수 있는 마법의 파일 형태랍니다.
*   **파일 다루기의 3단계 (Open -> Write -> Close)**
    1.  **`open("my_pokemon.csv", "w")` (열기)**: 새 빈 공책을 사서, 표지를 딱! 열고 펜을 든 상태예요. `"w"`는 Write, 즉 '글씨를 쓸 거야!'라는 뜻이에요.
    2.  **`writer.writerows(...)` (쓰기)**: 펜으로 공책에 피카츄, 이상해씨의 정보를 쓱싹쓱싹 적는 행동이에요.
    3.  **`file.close()` (닫기)**: 다 적었으면 공책을 덮어서 가방에 쏙 넣어야겠죠? 만약 공책을 안 덮으면 내용이 날아가거나 다른 사람이 공책을 망가뜨릴 수 있어요. 그래서 **파일은 무조건 마지막에 닫아줘야 해요!**

## 3단계: 포켓몬 사진첩 만들기 (`step3_image.py`)

도감에 글씨만 있으면 너무 심심하죠? 인터넷에 있는 진짜 포켓몬 사진을 다운받아서 내 컴퓨터에 '사진첩(폴더)'을 만들어 저장할 거예요.

### 💡 핵심 개념: 바이너리 쓰기 모드 (`"wb"`)
사진은 글씨(텍스트)가 아니죠? 사진은 수많은 색깔 점들이 컴퓨터만 아는 '외계어(0과 1)'로 적혀있는 덩어리예요.
*   2단계에서 글씨를 쓸 때는 그냥 `"w"` 모드를 썼지만, 그림을 도화지에 저장할 때는 **`"wb"` (Write Binary)** 모드를 써야 해요. "나는 일반 글씨가 아니라, 컴퓨터의 그림 물감(바이너리)을 칠할 거야!"라고 알려주는 거랍니다.

**코드 설명:**
*   **`os.makedirs`**: 내 컴퓨터에 'images'라는 이름의 새로운 빈 폴더(방)를 뚝딱 만들어줘요.

## 4단계: 텅 빈 도감 화면에 마법 부리기 (`step4_window.py`)

지금까지 우리는 까만 화면(콘솔)에 하얀 글씨가 줄줄 나오는 것만 봤어요. 이런 걸 **CLI (Command Line Interface)**라고 해요. 명령어를 키보드로만 치는 세상이죠.

하지만 우리가 매일 쓰는 스마트폰 앱이나 게임은 예쁜 그림도 있고 마우스로 클릭도 할 수 있죠? 이렇게 눈에 보이는 예쁜 창을 **GUI (Graphical User Interface)**라고 해요! 이제 우리 도감도 CLI에서 GUI로 멋지게 진화할 거예요.

### 💡 핵심 개념: Tkinter (마법의 미술 상자)
*   **`tkinter`**: 파이썬에서 창문을 그리고, 버튼을 만들고, 색칠해서 GUI를 만들 수 있게 해주는 기본 미술 상자예요.
*   **`window.mainloop()`**: 찰칵! 하고 사진을 찍듯이 한 번만 화면을 보여주면 창이 바로 꺼져버려요. `mainloop()`라는 마법의 주문을 걸어두면 "내가 끄기 전까지 계속 화면을 빙글빙글 돌면서 보여줘!" 하고 명령하는 거랍니다. 제일 마지막에 꼭 써야 해요!

## 5단계: 도감에 글씨와 사진 예쁘게 붙이기 (`step5_label_image.py`)

4단계에서 만든 빈 도감 창에 3단계에서 다운받은 피카츄 사진을 풀로 딱! 붙여볼까요?

### 💡 핵심 개념: Label (라벨)
*   **`Label` (라벨)**: 화면에 글씨를 쓰거나 사진을 붙일 수 있는 '포스트잇'이나 '스티커' 같은 거예요. 라벨 스티커 위에 '피카츄'라고 적어서 창문에 철썩! 붙이는 거죠.
*   **`ImageTk.PhotoImage`**: 파이썬이 사진을 도감 창에 예쁘게 띄울 수 있도록 사진 모양을 살짝 다듬어 주는 도구예요.
*   **`.pack()`**: 만든 라벨(스티커)을 창문 위에서부터 아래로 차곡차곡 예쁘게 쌓아서 붙여주는 명령어예요.

## 6단계: 무엇이든 찾아주는 마법의 버튼 만들기 (`step6_button.py`)

도감이라면 내가 원할 때 움직여야겠죠? 마우스로 누를 수 있는 '버튼'을 만들어서, 누를 때마다 화면이 바뀌게 만들어 볼 거예요. 우리가 무언가 행동을 했을 때 프로그램이 반응하는 것을 **이벤트(Event)**라고 해요.

### 💡 핵심 개념: Button과 Command
*   **`def click_button():`**: "만약 누군가 버튼을 누르면 이렇게 행동해!"라고 파이썬에게 미리 알려주는 작전 지시서예요.
*   **`Button` (버튼)**: 마우스로 딸깍! 누를 수 있는 진짜 버튼을 화면에 그려줘요.
*   **`command=click_button`**: 이 버튼과 방금 쓴 작전 지시서를 **연결해 주는 끈**이에요. 버튼을 누르면 끈이 당겨지면서 작전이 실행되는 거죠!

## 7단계: 실전 배틀 준비! 레벨업 능력치 계산기 (`step7_calculator.py`)

마지막 단계! 내 포켓몬이 레벨업을 하면 HP(체력)가 얼마나 올라가는지 자동으로 계산해 주는 똑똑한 계산기를 만들어 볼 거예요.

### 💡 핵심 개념: 데이터 타입 변환 (문자 -> 숫자)
*   **`Entry` (엔트리)**: 우리가 키보드로 글씨나 숫자를 직접 입력할 수 있는 하얀 빈칸이에요.
*   **`int()`**: 엄청 중요한 개념이에요! 우리가 빈칸에 숫자 `50`을 적어도, 컴퓨터는 그걸 "오", "영"이라는 **글씨(문자열)**로 생각해요. 글씨끼리는 더하기 빼기를 할 수 없겠죠? 그래서 `int()`라는 요술 지팡이를 휘둘러서 글씨를 더하기가 가능한 진짜 **숫자(정수, Integer)**로 변신시켜 줘야 해요.
*   **`+ - * /`**: 더하기, 빼기, 곱하기, 나누기를 하는 파이썬의 수학 기호예요. 컴퓨터는 계산을 세계에서 제일 잘한답니다!

## 8단계: 최종 보스! 실전 포켓몬 도감 완성하기 (`step8_final.py`)

지금까지 배운 모든 마법(GUI 창 만들기, 사진 붙이기, 글씨 쓰기, 버튼 누르기, 수학 계산하기)을 하나로 합쳐서, 진짜 그럴듯한 '피카츄 전력 분석기'를 만들어 볼 거예요! 원래 프로젝트에 있던 진짜 포켓몬 앱과 거의 똑같은 방식으로 움직이는 최종 보스 단계랍니다!

### 💡 핵심 개념: 변수(사전)와 함수 합치기
*   **`base_stats = {...}` (사전, Dictionary)**: 피카츄의 원래 능력치(종족값) 6가지를 하나의 상자에 예쁘게 담아두었어요. 부록에서 배운 JSON과 아주 비슷하게 생겼죠?
*   **여러 능력치 한 번에 계산하기**: 이제 [능력치 계산하기] 버튼 하나만 누르면, 파이썬이 순식간에 HP부터 스피드까지 6개의 수학 공식을 모두 계산해서 화면에 쫘르륵! 띄워줄 거예요.

**이 코드를 실행하면?**
짠! 노란색 배경의 예쁜 도감 창에 피카츄 사진이 뜨고, 레벨을 입력한 뒤 계산 버튼을 누르면 모든 능력치가 진짜 게임처럼 촤르륵 계산되어 나타난답니다!

## 9단계: 궁극의 진화! 진짜 포켓몬 도감 (모든 포켓몬 + API 연동) (`step9_real_pokedex.py`)

드디어 마지막의 마지막! 8단계 도감은 '피카츄' 한 마리만 분석할 수 있었죠? 이제 **모든 포켓몬의 이름**과 **성격** 데이터까지 전부 끌어와서 완벽한 '스마트 도감'을 만들 거예요!

### 💡 핵심 개념: 파일 읽어서 사전 만들기 & 성격(Nature) 적용하기
*   **모든 포켓몬 매핑하기**: 우리가 2단계에서 맛보았던 CSV 파일 기억하나요? 어른들이 미리 만들어둔 거대한 `pokemon_stats.csv` 파일에는 1000마리가 넘는 포켓몬의 한글 이름과 고유 번호가 들어있어요. 파이썬이 이 파일을 쭉~ 읽어서 완벽한 "한글 이름 ↔ 번호" 번역 사전을 자동으로 만들 거예요!
*   **성격(Nature)에 따른 보정치**: 포켓몬 게임에는 '성격'이라는 시스템이 있어요. 고집(공격 상승, 특수공격 하락), 겁쟁이(스피드 상승, 공격 하락)처럼요! `natures.json` 파일을 읽어와서 어떤 능력치가 오르고(1.1배) 내리는지(0.9배) 확인한 뒤 계산 공식에 쏙! 집어넣어 줍니다.
*   **API로 실시간 데이터 가져오기**: 콤보박스에서 포켓몬을 선택하면, 번호를 알아내서 즉시 인터넷 식당(API)에 종족값과 사진을 새로 주문해요! 다운로드한 사진은 폴더에 저장하지 않고 공중에서 바로 낚아채서 띄워줍니다 (`io.BytesIO`).

**이 코드를 실행하면?**
짠! 파란색 배경의 멋진 스마트 도감이 열려요. 검색창에 세상에 존재하는 모든 포켓몬 이름을 입력해서 찾을 수 있어요. **레벨을 타이핑하거나 성격을 바꾸는 즉시 엔터를 치지 않아도 능력치가 실시간으로 촤르륵! 바뀐답니다.** 능력치가 오르는 곳엔 🔺, 떨어지는 곳엔 🔻 이모지까지 표시돼요!

## 10단계: 보너스 도전 과제! 재능과 노력 계산하기 (`step10_challenge.py`)

지금까지 만든 도감도 완벽하지만, 포켓몬 게임의 진짜 고수들은 **5가지 요소**를 모두 따져서 능력치를 계산해요! 우리가 9단계까지 만든 앱은 종족값, 레벨, 성격 3가지만 계산했었죠. 이제 숨겨진 2가지 비밀을 파헤쳐 봅시다!

### 💡 포켓몬의 숨겨진 비밀: 재능(IV)과 노력(EV)
1.  **재능 (IV, 개체값)**: 같은 50레벨 피카츄 두 마리를 잡아도 능력치가 조금씩 달라요. 사람마다 태어날 때부터 키가 다르듯, 포켓몬도 태어날 때부터 **0점부터 31점**까지의 재능 점수를 무작위로 받기 때문이에요. (재능이 전부 31점인 천재 포켓몬을 '6V'라고 불러요!)
2.  **노력 (EV, 노력치)**: 포켓몬을 어떻게 훈련시켰느냐에 따라 능력치가 크게 달라져요. 달리기를 많이 한 꼬부기는 스피드가 빨라지죠! 한 능력치당 최대 **252점**까지 특훈을 시킬 수 있어요.

### 🎮 도전 미션: 코드를 고쳐서 진정한 도감을 완성하라!
`step10_challenge.py` 파일을 열어보세요. 화면에 표(Grid) 모양으로 예쁘게 '재능'과 '노력' 빈칸들을 만들어 두었어요. 하지만 계산하는 함수(`calculate_all_stats`) 안에는 아직 이 빈칸의 숫자를 가져오는 기능이 빠져있어요!

*   **힌트 1**: 파이썬 상자 이름은 `iv_inputs["HP"]` (재능 상자)와 `ev_inputs["HP"]` (노력 상자) 예요.
*   **힌트 2**: 이 상자 안에 적힌 글씨를 가져오려면 `.get()` 이라는 갈고리를 쓰고, 계산을 위해 숫자로 바꾸려면 `int()` 요술 지팡이를 써야 해요!
*   **미션**: 주석(초록색 글씨)으로 된 설명을 읽고, 고정되어 있는 숫자 31과 0을 지운 뒤 화면에서 숫자를 가져오는 코드로 직접 고쳐보세요!
